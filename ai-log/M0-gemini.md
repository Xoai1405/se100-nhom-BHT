1. Hướng dẫn các bước cơ bản deploy website bằng Cloudflare.
2. Cập nhật và render sơ đồ Mermaid (Class Diagram) theo đề tài E-learning mới, bọc trong thẻ code đúng cú pháp.
3. Hỗ trợ tạo nhánh `moc/M0`, xử lý lỗi không hiện nút Create Pull Request trên GitHub do 2 nhánh identical bằng cách tạo commit rỗng (`git commit --allow-empty`).
